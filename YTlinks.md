## 🎥 Project Demo

# 🔒 Phantom Lock

**Phantom Lock** is a smart, contactless door locking system that enhances security using intelligent authentication and IoT technology as a mini project developed as part of the **Useless Projects** series. The system verifies authorized users and grants or denies access in real time while maintaining an activity log.

## ✨ Features
- 🔐 Contactless authentication
- 📲 Real-time access monitoring
- 🚨 Unauthorized access alerts
- 📊 Access logs and event history
- 🌐 IoT-enabled remote monitoring

## 🛠️ Tech Stack
- ESP32
- RFID / NFC / Sensor-based Authentication
- Web Dashboard
- Wi-Fi Communication

## 🚀 Future Scope
- Face recognition integration
- Mobile app control
- Cloud-based access history
- Multi-user role management
