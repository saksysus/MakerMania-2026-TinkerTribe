# ✨ Laser Design Projects

This folder contains laser-cut design projects created as part of the **MakerMania 2026 Design and Fabrication Training Program**.

The objective of these projects was to develop skills in vector design, laser cutting workflows, fabrication planning, and design optimization for manufacturing. Through these projects, we explored how digital designs can be transformed into precise physical products using laser cutting technology.
